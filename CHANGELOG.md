# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-05-03

- Added command-line options for ticker, period, interval, custom dates, output folder, chart visibility, and auto-update behavior.
- Added styled Excel export with frozen headers, filters, number formatting, and readable column widths.
- Added validation for empty ticker symbols and invalid custom date ranges.
- Added GitHub-ready project metadata, license, dependency list, CI workflow, and documentation.
